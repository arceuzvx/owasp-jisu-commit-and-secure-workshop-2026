## 🎓 What You Will Learn
By participating in this workshop, you will learn:
- **Git Fundamentals**: `init`, `status`, `add`, `commit`, `log`, `push`, and `branches`.
- **GitHub Workflow**: Cloning, forking, and opening Pull Requests (PRs).
- **GitHub Pages**: Deploying your own customized website for free.
- **Secure Git Practices**: Managing `.gitignore`, avoiding secrets leaks, and understanding OWASP A02 & A05.
- **Open-source Contribution**: How to effectively contribute to a community project.

## 🚀 Quick Start
Ready to build your site? 
1. Click the **"Use this template"** button at the top of this repository to create your own copy.
2. Clone your new repository to your local machine.
3. Customize the HTML/CSS with your chosen theme.
4. Deploy to GitHub Pages! 

See the full [WORKSHOP.md](WORKSHOP.md) guide for detailed step-by-step instructions.

## 🔄 Git Workflow Basics
Here are the essential commands you'll use:
- `git init`: Initialize a new Git repository.
- `git status`: Check the status of your files.
- `git add <file>`: Stage files for a commit.
- `git commit -m "Message"`: Save your changes with a descriptive message.
- `git log`: View the history of your commits.
- `git push origin main`: Upload your local commits to GitHub.
- `git branch` & `git switch`: Manage and switch between different streams of work.
- **PRs**: Propose your changes to the main project!

## 🌐 GitHub Pages Deployment
1. Go to your repository **Settings**.
2. Navigate to **Pages** in the left sidebar.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` (or your default branch) and `/root`, then save.
5. In a few minutes, your site will be live!
