# ✅ Student Checklist
Track your progress through the Commit & Secure workshop!

Copy this checklist into a note or print it out. Check off each step as you complete it!

### 🏁 Getting Started
- [ ] Created a GitHub account
- [ ] Installed Git on my computer (`git --version` works)
- [ ] Configured Git username (`git config --global user.name "Your Name"`)
- [ ] Configured Git email (`git config --global user.email "you@example.com"`)

### 🎨 Building My Website
- [ ] Clicked "Use this template" to create my own repository
- [ ] Chose a theme (Cream / Hacker / Corporate / Retro)
- [ ] Customized my name and bio in index.html
- [ ] Updated my GitHub and social links
- [ ] Updated my skills/interests
- [ ] Previewed my website locally (opened index.html in browser)

### 🚀 Deploying to GitHub Pages
- [ ] Pushed my changes to GitHub
- [ ] Enabled GitHub Pages (Settings → Pages → Deploy from branch)
- [ ] Confirmed my website is live at `https://<username>.github.io/<repo-name>`

### 🔐 Security Practices
- [ ] Reviewed the .gitignore file and understand why it exists
- [ ] Reviewed the security demo (security-demo/ folder)
- [ ] I understand why API keys should never be committed
- [ ] I understand what OWASP A02 and A05 mean

### 🤝 Contributing Back
- [ ] Cloned the original Commit & Secure repository
- [ ] Created a new branch (`git switch -c add-my-profile`)
- [ ] Created my contributor file (`contributors/<my-github-username>.json`)
- [ ] Set `"completed": true` in my JSON file
- [ ] Committed my changes with a descriptive message
- [ ] Pushed my branch to GitHub
- [ ] Opened a Pull Request

### 🎖️ Earning My Badge
- [ ] My Pull Request was reviewed and merged
- [ ] My badge was automatically generated
- [ ] I can see myself in the Hall of Fame
- [ ] I added my badge to my own repository README (optional)

### 🎉 Bonus Challenges
- [ ] Helped another student with Git commands
- [ ] Explored another theme and compared designs
- [ ] Read the SECURITY.md file completely
- [ ] Starred the repository ⭐

🏆 Congratulations! You've completed the Commit & Secure workshop. You now know Git, GitHub, GitHub Pages, and secure development practices!
