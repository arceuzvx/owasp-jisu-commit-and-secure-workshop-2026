# ✅ Student Checklist

Track your progress through the Commit & Secure workshop!

Copy this checklist into a note or print it out. Check off each step as you complete it!

---

### 🏁 Getting Started
- [ ] Created a GitHub account
- [ ] Installed Git on my computer (`git --version` works)
- [ ] Configured Git username (`git config --global user.name "Your Name"`)
- [ ] Configured Git email (`git config --global user.email "you@example.com"`)

### 🍴 Forking the Repository
- [ ] Forked the original Commit & Secure repository
- [ ] Cloned MY fork to my computer
- [ ] Verified I'm on the `main` branch (`git branch`)

### 🎨 Building My Website (on `my-website` branch)
- [ ] Created the `my-website` branch (`git switch -c my-website`)
- [ ] Chose a theme (Cream / Hacker / Corporate / Retro)
- [ ] Copied theme files to the root folder
- [ ] Customized my name and bio in `index.html`
- [ ] Updated my GitHub and social links
- [ ] Updated my skills/interests
- [ ] Previewed my website locally (opened `index.html` in browser)
- [ ] Committed my changes (`git add` + `git commit`)
- [ ] Pushed the `my-website` branch (`git push origin my-website`)

### 🚀 Deploying to GitHub Pages
- [ ] Went to my fork's Settings → Pages
- [ ] Set source to **`my-website`** branch (not `main`!)
- [ ] Confirmed my website is live at `https://<username>.github.io/<repo-name>`
- [ ] Copied my live website URL

### 🔐 Security Practices
- [ ] Reviewed the `.gitignore` file and understand why it exists
- [ ] Explored the security demo (`security-demo/` folder)
- [ ] I understand why API keys should never be committed
- [ ] I understand what OWASP A02 and A05 mean

### 🤝 Contributing Back (on `add-my-profile` branch)
- [ ] Switched back to `main` (`git switch main`)
- [ ] Created the `add-my-profile` branch (`git switch -c add-my-profile`)
- [ ] Created `contributors/<my-github-username>.json`
- [ ] Set `"completed": true` in my JSON file
- [ ] My JSON includes all 5 fields (name, github, website, theme, completed)
- [ ] Committed my contributor file
- [ ] Pushed the `add-my-profile` branch (`git push origin add-my-profile`)
- [ ] Opened a Pull Request to the **original** repository

### 🎖️ Earning My Badge
- [ ] My Pull Request was reviewed and merged
- [ ] My badge was automatically generated by GitHub Actions
- [ ] I can see myself in the Hall of Fame
- [ ] I added my badge to my own repository README (optional)

### 🎉 Bonus Challenges
- [ ] Helped another student with Git commands
- [ ] Explored another theme and compared designs
- [ ] Read the SECURITY.md file completely
- [ ] Starred the repository ⭐

---

### 🔍 Quick Branch Reference

| I want to... | Go to this branch |
|---|---|
| Build my website | `git switch my-website` |
| Make my contribution | `git switch add-my-profile` |
| Start fresh / check original | `git switch main` |

---

🏆 **Congratulations!** You've completed the Commit & Secure workshop. You now know Git, GitHub, GitHub Pages, branching, and secure development practices!
